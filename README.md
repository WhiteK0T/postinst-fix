# 🛠️ `postinst-fix` — Пatcher для `.postinst` скриптов Debian/Ubuntu

Безопасный скрипт на Bash для автоматического исправления `.postinst` файлов в `/var/lib/dpkg/info/`. Добавляет ` || true` к командам `systemd-sysusers`, которые заканчиваются на `.conf`, предотвращая сбои установки/обновления пакетов.

---

## 📌 Назначение
В некоторых дистрибутивах (Debian 12+, Ubuntu 22.04+) скрипты установки пакетов вызывают `systemd-sysusers` с путями к `.conf` файлам, которые могут отсутствовать или вызывать ошибки прав доступа. Это приводит к аварийному завершению `dpkg` и `apt`. Скрипт вносит минимальное, целевое изменение, делая такие команды безопасными для выполнения без поломки цепочки установки.

---

## 📋 Требования
- ОС: Debian, Ubuntu или совместимые дистрибутивы
- Bash ≥ 4.0 (поддержка `mapfile`, `shopt -s nullglob`)
- Стандартные утилиты: `grep`, `sed`, `cp`, `mkdir`, `date`
- Права `root` (запуск через `sudo`)

---

## 🚀 Установка и использование

### 1. Скачайте и сделайте скрипт исполняемым
```bash
curl -fsSL https://raw.githubusercontent.com/WhiteK0T/postinst-fix/refs/heads/main/postinst-fix.sh -o postinst-fix.sh
chmod +x postinst_fix.sh
```

### 2. Проверка изменений (рекомендуется перед применением)
```bash
sudo ./postinst_fix.sh --dry-run
cat ~/postinst_fix.log
```

### 3. Применение исправлений
```bash
sudo ./postinst_fix.sh
```

### 4. Проверка результата
```bash
cat ~/postinst_fix.log
# Просмотр созданных бэкапов:
ls -l /tmp/postinst_backups_*/
```

## ⚙️ Параметры командной строки
| Флаг | Описание |
|------|----------|
| `--dry-run` или `-n` | Режим предпросмотра. Файлы не изменяются, только выводятся планируемые правки |
| *(без параметров)* | Выполняет реальную модификацию с созданием бэкапов |

---

## ⚠️ Важные предупреждения
> 🔴 **Скрипт модифицирует системные файлы** в `/var/lib/dpkg/info/`. Это не поддерживается официально и может быть отменено при обновлении пакетов через `apt upgrade`.
> 
> ✅ Все изменения **идемпотентны** (повторный запуск не дублирует правки).
> ✅ Оригиналы сохраняются в `/tmp/postinst_backups_YYYYMMDD_HHMMSS/` перед изменением.
> ✅ Рекомендуется тестировать на виртуальной машине или резервной копии системы.
> ✅ Скрипт является **временным обходным решением**, а не официальным патчем.

---

## 📖 Как это работает
1. Скрипт сканирует все `*.postinst` файлы в `/var/lib/dpkg/info/`
2. Ищет строки, содержащие `systemd-sysusers`, но ещё не содержащие ` || true`
3. Фильтрует только те, что заканчиваются на `.conf`
4. В режиме `--dry-run` выводит сравнение, иначе применяет `sed` и создаёт бэкап
5. Логирует все действия в `~/postinst_fix.log`

## 🛡️ Безопасность и откат
При возникновении проблем после применения:
```bash
# 1. Найдите нужный бэкап
ls /tmp/postinst_backups_*/

# 2. Восстановите оригинал (замените имя файла)
sudo cp /tmp/postinst_backups_*/имя_пакета.postinst /var/lib/dpkg/info/имя_пакета.postinst

# 3. Верните права доступа
sudo chown root:root /var/lib/dpkg/info/имя_пакета.postinst
sudo chmod 755 /var/lib/dpkg/info/имя_пакета.postinst

# 4. При необходимости переустановите пакет
sudo apt install --reinstall имя-пакета
```
