# 📜 Changelog

---

## 1.0.0 (2026-05-14)

### ✨ Добавлено (Added)
- `set -euo pipefail` для строгого режима выполнения Bash
- Проверка прав `root` на старте (`$EUID -ne 0`) вместо множественных вызовов `sudo` внутри цикла
- Автоматическое резервное копирование оригинальных файлов в `/tmp/postinst_backups_YYYYMMDD_HHMMSS/`
- Режим предпросмотра `--dry-run` / `-n` для безопасного тестирования без изменения файлов
- Централизованное логирование с таймстампами через `exec >> "$LOGFILE" 2>&1`
- Визуальные маркеры в логе для быстрого сканирования статусов

### 🔧 Изменено (Changed)
- Логика замены: убрано дублирование `.conf` в паттерне `sed` (`s/\.conf$/\.conf || true/`)
- Обработка `grep`: добавлен `|| true` для предотвращения аварийного выхода при отсутствии совпадений
- Фильтрация строк: точечная проверка на окончание `.conf$` перед логированием и заменой
- Структура скрипта: вынесены настройки, аргументы, функции инициализации в отдельные логические блоки
- Счётчик изменённых файлов для итоговой статистики

### 🐛 Исправлено (Fixed)
- Падение скрипта при пустом результате `grep` из-за `set -e`
- Неэффективное повторное открытие файла лога в каждой итерации цикла
- Риск потери оригинальных `.postinst` файлов при сбоях `sed` или прерывании выполнения

### 🛡️ Безопасность (Security)
- Изоляция бэкапов в временной директории с уникальным таймстампом
- Жёсткий запрет выполнения без привилегий `root`
- Защита от повторных модификаций (идемпотентность) через `grep -v "|| true"`
